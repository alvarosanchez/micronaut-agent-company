This lightweight project exists only to anchor recurring company-operating routines.

It does not replace the GitHub sync plugin's per-repository projects, and it is not where normal Micronaut repository delivery work should live. Its routines exist to keep the company healthy: proactive security sweeps, self-improvement, and other recurring internal maintenance that should continue even when the synced GitHub queue is temporarily quiet.
