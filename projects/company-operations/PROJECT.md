This lightweight project exists to hold a very small amount of internal company-operating work: one bootstrap verification issue plus the recurring routines that keep the company healthy.

It does not replace the GitHub sync plugin's per-repository projects, and it is not where normal Micronaut repository delivery work should live. Use it only for startup verification and other internal maintenance such as proactive security sweeps and self-improvement that should continue even when the synced GitHub queue is temporarily quiet.
