Create the first working triage rubric for this repository cluster.

Define how the company will identify:

- actionable issues
- needs-clarification issues
- duplicates
- stale or superseded items
- out-of-scope requests
- PRs that are merge-ready versus PRs that require maintainer action

Keep the rubric simple enough to run every sweep without debate.
