This project is the company's steady-state operating program.

Use it to keep the selected Micronaut repository cluster moving through the agreed lifecycle:

- synced issues arrive in `BACKLOG` assigned to QA
- humans promote actionable work to `TODO`
- QA types and routes the work
- Architect, Micronaut Engineer, and Technical Writer execute
- QA verifies
- Core Reviewer performs structural review and creates PRs
- Micronaut Engineer drives PR follow-through until maintainers merge
