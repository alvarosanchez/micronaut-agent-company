Prepare respectful, evidence-backed closure proposals for open issues that should not move forward to implementation.

Typical cases:

- duplicates with a canonical issue already tracked
- unreproducible bugs after a serious reproduction attempt
- stale items that no longer map to supported versions or current product direction
- out-of-scope or superseded requests

For each candidate:

- capture the evidence behind the recommendation
- draft the exact explanation that should later appear on GitHub
- request board approval in Paperclip
- wait for the human approval comment before posting the closure explanation and closing the issue with the sync plugin tools
