Work through open `type: question` issues in the selected repository cluster.

For each question:

- confirm the issue is actually a question and not a disguised bug, docs issue, or enhancement request
- gather the smallest set of facts needed for a correct maintainer-quality answer
- ask the Architect for technical clarification when the answer would otherwise be speculative
- prepare a concise answer proposal for board approval in Paperclip
- wait for the human approval comment before posting on GitHub
- once approved, publish the answer through the sync plugin tools and close or resolve the issue according to maintainer direction
